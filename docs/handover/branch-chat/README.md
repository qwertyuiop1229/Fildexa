# 枝分かれしたチャットからの引き継ぎ

[枝分かれ · HTMLプレビューサイト作成](chatgpt-conversation://6affb6f3-7e20-83ee-bc62-072116b7ceaf)

- 単体HTML、ZIP、HTML・CSS・JSのフォルダ、基本的なVite/TypeScript/JSX/TSXの読み込み。複雑なビルドは元プロジェクトで行った静的出力を開く。
- プレビューはPC・スマホ・カスタムサイズ、二段階の拡大、タッチでの縮小、幅を変えられるパネル、暗色テーマ、閉じる・リセットを持つ。サンプルを使い方から開ける。
- 外部通信許可とゲームのポインターロック許可は独立。通信の表示はブラウザから観測可能な項目に限定する。保存データは許可したプロジェクトごとに復元・削除できる。
- ローカル互換モードは `node server.mjs` で起動。認証・PWA・IndexedDBの検証は、信頼するアプリのローカル環境や別オリジンのテスト環境で行う。
- 枝チャットで案内された移行用ZIPと単体HTMLは配布形態として記録。今回のFirebase版は、Sitesの公開v8に対応するGitコミットから直接取り出した複数ファイル構成を採用した。
- 保存領域はオリジン単位のため、Sites側のテーマ・パネル幅・プロジェクトの保存データは新URLに自動移行されない。
