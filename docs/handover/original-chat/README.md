- Fildexaを、ファイルを開く・理解する・動かす・検証するためのワークスペースに育てる。
- 既存のZIP・フォルダ・HTMLプレビュー、デバイス表示、開発ツール、検証ラボ、比較、接続機能を引き継ぐ。基準版はChatGPT Sitesのバージョン8。Gitタグ `zipstage-v8` に保存。
- ファイルは、形式・容量などの基本情報、専用ビューアー、編集・解析・比較の順に対応を深める。
- UIは種類に応じて操作を切り替える。青緑のアイコンを継承し、PCは分割、iPadは折りたたみ、スマホは全画面切替を基本とする。タッチ、キーボード、動きを減らす設定も確認する。
- 現行コードにある機能と動作確認の結果は区別して記録する。iPad Safariの実機操作も確認対象に含める。
